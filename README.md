# Critical Load - 2D Physics-Based Balance Game

Critical Load, Unity oyun motoru kullanılarak C# ile geliştirilmiş, 2D fizik tabanlı bir denge ve simülasyon oyunudur.

Critical Load is a 2D physics-based balance and simulation game developed with C# using the Unity game engine.

---

## 🚀 Özellikler / Features

### 🇹🇷 Türkçe
- **Dinamik Zorluk Ayarlama (DDA):** Oyun süresine ve oyuncu performansına göre parametrik olarak değişen nesne üretimi (spawn) algoritmaları.
- **2D Fizik Simülasyonu:** Rigidbody2D, sürtünme ve ağırlık merkezi hesaplamaları ile gerçekçi çarpışma (Collider) yönetimi.
- **Yazılım Mimarisi:** Nesne yönelimli programlama (OOP), Singleton tasarım deseni (GameManager, AudioManager) ve sahneler arası veri yönetimi.
- **Özel UI/UX Etkileşimleri:** Pixel Art görseller için IPointerDownHandler ve EventSystem tabanlı özel buton ve arayüz mekanizmaları.
- **Oyun İçi Sistemler:** Dinamik puanlama, PlayerPrefs tabanlı skor kaydı, can (kalp) ve alan temizleyen bomba mekanikleri.

### 🇬🇧 English
- **Dynamic Difficulty Adjustment (DDA):** Object spawning algorithms that parametrically adapt based on playtime and player performance.
- **2D Physics Simulation:** Realistic collision management using Rigidbody2D, friction physics, and center-of-mass calculations.
- **Software Architecture:** Object-Oriented Programming (OOP), Singleton design patterns (GameManager, AudioManager), and cross-scene data persistence.
- **Custom UI/UX Interactions:** Specialized UI button mechanics built with EventSystem and IPointerDownHandler tailored for Pixel Art assets.
- **In-Game Systems:** Dynamic scoring, local high-score persistence via PlayerPrefs, health mechanics, and area-clearing bomb mechanics.
